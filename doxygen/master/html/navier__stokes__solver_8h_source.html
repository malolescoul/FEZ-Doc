30/**
31 * A base class for Navier-Stokes solvers.
32 *
33 * This class handles the common tasks to all Navier-Stokes related solvers,
34 * namely :
35 *
36 * - creating and handling the mesh (fixed and/or moving)
37 * - creating the system parallel matrix and vectors
38 * - creating the mesh- and NS-related boundary conditions (constraints)
39 * - advancing the time integration and solving the nonlinear system
40 * - computing errors on velocity, pressure and mesh position, if applicable
41 *
42 * Solver-specific tasks (additional boundary conditions, outputting results,
43 * computing errors, etc.) are handled by overloading the "solver_specific"
44 * routines, which by default do nothing in this base class.
45 * Other functions, such as setup_dofs, are marked virtual to allow overloading
46 * by solvers requiring a specific treatment, but not all solvers are required
47 * to overload these functions.
48 *
49 * This class does *not* handle the following, which must then be
50 * implemented by each derived solver:
51 *
52 * - creation of the FiniteElements (e.g., FESystem or FECollection), which
53 * depend on the fields layout and specificities of each solver
54 * - matrix and rhs assembly
55 * FIXME: This means that currently, each solver assembles its whole set of
56 * equations. In particular, the Navier-Stokes eq. are duplicated across the
57 * solvers, which is not ideal.
58 *
59 */
