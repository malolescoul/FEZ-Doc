15/**
16 * A class storing the data that need to be duplicated for each time
17 * subinterval when using the transient fixed point mesh adaptation method for
18 * unsteady simulations. To use a common interface, this structure is also used
19 * for non-adaptive simulations, either steady or unsteady, in which case
20 * this class stores the data for the single, full simulation time interval.
21 *
22 * This class stores and owns (in the sense of memory management) the
23 * triangulations and dof handlers, present and previous solutions vectors, as
24 * well as the Riemannian metrics needed for anisotropic mesh adaptation.
25 *
26 * The intended use of this class is to have each solver own one such object,
27 * and store "observer" pointers, in the form of
28 * raw, non-owning pointers, to the triangulation, dof handler, etc. associated
29 * with the index-th time subinterval.
30 *
31 * A more fitting name for this class would maybe be "SolverDataCollection".
32 */
