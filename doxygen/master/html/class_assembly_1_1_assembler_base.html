Description détaillée

template<typename ScratchData, typename CopyData>
class Assembly::AssemblerBase< ScratchData, CopyData >

Base class for an object whose job is to assemble equations on an element, that is, to increment the local matrix and right-hand side vector.

This design is borrowed from the chaos-polymtl/lethe project.
