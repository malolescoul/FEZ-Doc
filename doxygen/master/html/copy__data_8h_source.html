11/**
12 * A CopyData is a helper structure used to copy the local matrix and RHS
13 * contributions to the global system, see for instance the deal.II doc of
14 * meshworker/copy_data.h and the run() functions in work_stream.h.
15
16 * This class describes a CopyData which can be used with solvers where one
17 * FESystem is defined on a part of the domain, and one or more other systems
18 * are defined on some other partitions, using the hp tools from deal.II in the
19 * spirit of the step-46 examples. To this end, this class is templated on the
20 * number of partitions, the regular CopyData structure being simply the case
21 * n_hp_partitions = 1.
22 *
23 * This class basically holds "n_hp_partitions" copies of
24 * the local matrix, local rhs and local dof indices, which is exactly what a
25 * MeshWorker::CopyData does, and is thus derived from that class.
26 *
27 * This class's name is CopyDataBase, so that we can use an alias in the
28 * definition of the various derived solvers, for instance:
29 *
30 * using CopyData = CopyDataBase<1>;
31 *
32 * This is not possible if this class's name is CopyData, as otherwise the
33 * compiler says that this typedef changes the meaning of CopyData. Thus, we're
34 * simply using any other name that CopyData, which is then used as the local
35 * alias in most solvers.
36 */
