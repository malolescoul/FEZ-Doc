Compare each Jacobian matrix computed in assemble_local_matrix to its finite differences approximation obtained by perturbing the right-hand side (Newton residual). To allow comparing for multiple Newton iterations and/or time steps, this function does not throw if the difference between the analytical matrix entries and their FD counterpart exceeds a prescribed tolerance, but instead prints the local matrices and the problematic entries.
