template<typename VectorType>
virtual void NonLinearSolver< VectorType >::solve ( const TimeHandler & time_handler)
pure virtual

Solve the nonlinear problem (with e.g. Newton's method in the associated derived class).

If the simulation is steady-state or if adaptive time stepping is disabled, the solver will throw is no solution was found. For unsteady simulations with adaptive time steps, the solver does not throw on failure, to allow trying again with a smaller time step.
