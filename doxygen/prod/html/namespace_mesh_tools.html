Mark a physical band around the sampled zero contour of a scalar field. Criteria are +1 (refine), 0 (keep), -1 (coarsen). Cell sizes use the mapped mesh for ALE and the reference mesh otherwise. The contour and cell geometry are piecewise linear approximations.
