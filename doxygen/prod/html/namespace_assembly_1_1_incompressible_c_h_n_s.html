Description détaillée

A namespace gathering the assembly routines for the (quasi-)incompressible Cahn-Hilliard Navier-Stokes models.

Documentation du type de l'énumération

◆ AssemblyFlags

enum Assembly::IncompressibleCHNS::AssemblyFlags : unsigned int

These flags are used to specify which terms to assemble in addition to the base incompressible CHNS system.

Valeurs énumérées
chns 

Assemble the incompressible CHNS system without any stabilization.

stabilization 

Add SUPG/PSPG stabilization forms for the Navier-Stokes equations.

tracer_stabilization 

Add SUPG stabilization form for the phase tracer equation.

moving_mesh 

Account for moving mesh contributions (ALE).

enlarged 

Assemble the enlarged (psi) tracer Helmholtz reconstruction. Implies moving_mesh (the enlarged solver is ALE only).

ding_horriche 

Assemble the Ding-Horriche CHNS model instead of the default Abels model. This changes the potential scaling, the capillary momentum force (mu*grad(phi) instead of phi*grad(mu)) and drops the diffusive inertia term.
