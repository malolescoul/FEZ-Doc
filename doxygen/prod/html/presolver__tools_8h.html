template<int dim>
std::unique_ptr< ElasticitySolver< dim > > create_elasticity_presolver ( const ParameterReader< dim > & param,
const bool with_enlarged_psi = false,
parallel::DistributedTriangulationBase< dim > * reference_triangulation = nullptr )

Build and run the elasticity presolver that pre-positions the mesh for a CHNS-ALE simulation. Returns nullptr when the presolver is disabled. The returned solver owns the presolved mesh position and optional enlarged psi field, which the CHNS solver injects into its initial solution.
