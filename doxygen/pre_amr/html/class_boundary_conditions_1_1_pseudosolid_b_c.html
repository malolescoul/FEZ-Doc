◆ constrain_x

template<int dim>
bool BoundaryConditions::PseudosolidBC< dim >::constrain_x = true

For an input_function boundary, select which mesh-position components are strongly constrained by the x/y/z function. Leaving a component unconstrained lets the pseudosolid solver determine it (e.g. a wavemaker whose horizontal motion is prescribed while the vertical slides freely). At least one component must be constrained.
