Description détaillée

template<int dim>
class VectorFunctionFromComponents< dim >

Vector-valued function described by up to 3 individual ParsedFunctions. The parameter lower is the first vector component in the solution vector.

This Function does no override the set_time function, instead it assumes that time has been correctly updated in each underlying ParsedFunction.
