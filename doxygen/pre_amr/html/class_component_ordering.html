Description détaillée

A ComponentOrdering describes the lower and upper component indices for a given solver. For now, all solvers work in a monolithic fashion, solving their complete system of PDEs in a unique coupled system.

Each derived class must specify the [lower, upper) interval for its variables.

FIXME: These orderings should be known at compile time.
