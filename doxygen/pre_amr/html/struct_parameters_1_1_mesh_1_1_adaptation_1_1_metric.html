◆ n_fixed_point

unsigned int Parameters::Mesh::Adaptation::Metric::n_fixed_point

Number of fixed point iterations to perform, to converge the mesh-solution pair. For steady simulations, this is the number of times the solver is run, and the mesh is adapted this number of times minus one. For unsteady simulations, this is the number of times the whole simulation is run, and the meshes are adapted on sub-intervals, this number of times minus one.
