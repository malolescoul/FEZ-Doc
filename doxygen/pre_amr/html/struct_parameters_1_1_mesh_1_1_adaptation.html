◆ Strategy

enum class Parameters::Mesh::Adaptation::Strategy
strong

Available mesh adaptation strategies:

  • adaptation with a Riemannian metric, originating from one or more FE fields. For simplicial meshes only, as anisotropic metric-based meshing libraries exist only for simplicial meshes for now.
  • (not yet implemented:) hierarchical adaptation, using deal.II's routines and p4est. For quad/hex meshes only.
